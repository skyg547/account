# 📜 Config Server (중앙 설정 서버) - "MSA 레시피 본사"

## 1. 초보자를 위한 개념 설명
수십 개의 마이크로서비스가 각각 자기 폴더 안에 `application.yml`을 가지고 있다면, 데이터베이스 비밀번호가 하나 바뀔 때마다 모든 폴더를 뒤져서 파일을 고치고 서버를 껐다 켜야 합니다.

**Config Server**는 프랜차이즈 **본사**입니다. 각 서비스(지점)들은 켜질 때 이 본사(포트 8888)에 접속하여 "나 master-data인데, 내 설정 파일(레시피) 좀 줘!" 라고 요청해서 받아갑니다. 따라서 개발자는 오직 본사의 `config-repo` 폴더(나중에는 Github 저장소)에 있는 파일들만 고치면 모든 지점의 설정이 업데이트됩니다!

## 2. 이 폴더의 역할
- `ConfigServerApplication`: 8888 포트로 켜져서 설정 파일(yml)을 서빙해 주는 간단한 웹 서버입니다.
- 이 모듈은 오직 본사 데스크 역할만 수행하며, 실제 각 서비스들의 설정 파일 내용물은 **프로젝트 최상단의 `config-repo` 폴더**에 모아둡니다.

## 3. 실행 방법
전체 시스템 중에서도 **가장 먼저** (또는 Discovery와 동시에) 켜져야 하는 서버입니다. 다른 서비스들이 켜질 때 이 서버에서 설정을 받아와야 하기 때문입니다.

```bash
./gradlew :config-server:bootRun
```
브라우저에서 `http://localhost:8888/master-data/default` 처럼 주소를 치면, 본사가 `master-data` 지점에게 내려줄 레시피(설정) 내용이 JSON 형태로 아름답게 나옵니다!
