# 🎨 프론트엔드 레이아웃 및 UI/UX 설계서

본 문서는 '모던 재무 시스템'의 주요 화면 레이아웃 구성과 사용자 경험(UX) 전략을 설명합니다.

## 1. 전역 레이아웃 구조 (Shared Layout)

시스템의 모든 페이지는 일관성을 위해 다음과 같은 기본 프레임을 공유합니다.

*   **Side Navigation (가로형):** 좌측에 위치하며, 도메인별 주요 메뉴(대시보드, 전표관리, 원장조회, 정산, 자산관리)를 포함합니다. 접기/펼치기 기능을 지원합니다.
*   **Top Header:** 현재 페이지 타이틀, 알림 아이콘, 실시간 환율 정보, 그리고 사용자 프로필(로그아웃 포함)을 배치합니다.
*   **Breadcrumbs:** 현재 나의 위치를 나타내어 복잡한 금융 메뉴 사이에서 길을 잃지 않게 돕습니다.
*   **Main Content Area:** 실제 업무가 이루어지는 영역으로, 글래스모피즘 효과가 적용된 화이트/다크 보드 카드 형태를 띱니다.

## 2. 주요 화면별 상세 설계

### ① 대시보드 (Main Dashboard)
*   **목적:** 회사의 재무 상태를 한눈에 파악.
*   **주요 컴포넌트:**
    *   **자산/부채 요약 위젯:** 큰 글씨와 트렌드 차트(Line Chart).
    *   **실시간 전표 유입 현황:** 카프카를 통해 들어오는 전표를 애니메이션과 함께 리스트로 노출.
    *   **마감 디데이(D-Day):** 결산 마감까지 남은 시간을 긴박하게 표시.

### ② 전표 관리 (Journal Entry)
*   **목적:** 자동 분개 내역 조회 및 수동 전표 입력.
*   **주요 컴포넌트:**
    *   **그리드(Grid):** 수천 건의 전표를 빠르게 조회할 수 있는 가상 스크롤 그리드.
    *   **분개 상세 모달:** 차변(Dr) / 대변(Cr) 합계가 일치하지 않으면 빨간색 경고를 띄우는 스마트 폼.

### ③ 원장 조회 (General Ledger)
*   **목적:** 계정별 원동 및 잔액 분석.
*   **주요 컴포넌트:**
    *   **계정 과목 트리:** 계층형 구조(자산 -> 유동자산 -> 현금)로 계정을 선택할 수 있는 트리 뷰.
    *   **기간별 비교 차트:** 지난달 대비 지출 추이를 보여주는 막대 차트.

## 3. 디자인 시스템 및 테마

*   **Color Palette:**
    *   **Primary:** `#6366f1` (Indigo - 신뢰와 현대적 감각)
    *   **Success:** `#22c55e` (Green - 차변/대변 일치)
    *   **Danger:** `#ef4444` (Red - 불일치 및 오류)
    *   **Background:** 다크 모드 기반의 딥 네이비(`0f172a`)와 반투명 반사 효과.
*   **Typography:** 'Inter' 또는 'Pretendard' (가독성이 높고 전문적인 폰트).

## 4. 초보자를 위한 개념 설명
*   **레이아웃:** 건물의 인테리어 구조와 같습니다. 어디에 메뉴가 있고, 어디서 실제 작업을 할지 미리 정하는 것입니다.
*   **가상 스크롤 그리드:** 데이터가 수만 장 있어도, 내 눈에 보이는 부분만 화면에 그려서 컴퓨터가 느려지지 않게 하는 마법 같은 기술입니다.
*   **차변(Dr) / 대변(Cr):** 회계의 양팔 저울입니다. 왼쪽(차변)과 오른쪽(대변)의 합계는 항상 같아야 하며, 우리 시스템은 이를 실시간으로 체크합니다.
