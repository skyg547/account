## Problem statement

A condition-free mandatory task and gate can be manually completed/passed, satisfying final close. No required AP/AR/lease/loan readiness, outstanding journal/adjustment, annual transfer or ECL reconciliation evidence is queried.

## Reproduction / evidence

Static path plus P16's domain sequence demonstrates flag-based readiness. JSON conditions correctly fail closed when configured because no typed evaluator exists; however, omitting conditions permits closure without source evidence. This finding concerns missing policy-required controls, not the mere existence of manual checklist items.

Executed diagnostic observations: `P16` in [probe-results.json](../evidence/probe-results.json); source: [AuditProbes.java](../evidence/AuditProbes.java). Probe PASS confirms the observation, not remediation.

## Financial / architectural impact

Periods can close with unfinished subledgers, unposted adjustments or unreconciled provision results.

## Proposed solution

Define mandatory close controls by scope and consume typed, immutable evidence with source run IDs, ledger cutoff, totals and freshness.

## Acceptance criteria

- [ ] Missing, failed, stale or mismatched required evidence blocks final close.
- [ ] Exercise AP/AR/lease/loan status, outstanding journal adjustments, ECL summary-to-posted reconciliation and annual transfer where applicable.
- [ ] Manual overrides, if policy allows them, require distinct approval and durable reason/evidence.
- [ ] Add regression coverage that fails on the audited version and passes after remediation; preserve existing financial controls.
