## Problem statement

lockPeriod stores a local PeriodLock, while isClosed reads only master CLOSED/PERMANENTLY_CLOSED. Starting a calendar changes its local status to IN_PROGRESS but leaves the master period OPEN. The Journal status adapter likewise does not consult local locks/calendar state.

## Reproduction / evidence

Static trace: OPEN master period + GENERAL PeriodLock or IN_PROGRESS calendar still returns open to Journal. P07 additionally shows a supplied CLOSING_IN_PROGRESS status fails open; that literal is not a current master enum value, so the probe is an unknown-state defense test, not evidence that master currently stores it.

Executed diagnostic observations: `P07` in [probe-results.json](../evidence/probe-results.json); source: [AuditProbes.java](../evidence/AuditProbes.java). Probe PASS confirms the observation, not remediation.

## Financial / architectural impact

Posting can continue while operators believe the period is locked and while closing evidence is being assembled.

## Proposed solution

Define one authoritative admission decision covering period state, active locks and close progress; accept only explicitly allowed states and integrate it with GL07's commit fencing.

## Acceptance criteria

- [ ] Ordinary posting is denied for active lock and closing-in-progress states across local/remote deployments.
- [ ] Missing/unknown state fails closed; explicitly governed adjustment posting remains possible if policy requires it.
- [ ] Lock/unlock and start/close transitions are observable and tested through Journal's actual status port.
- [ ] Add regression coverage that fails on the audited version and passes after remediation; preserve existing financial controls.

## Test gap and verification limits

Tests establish CLOSED rejection but not a lock/calendar-to-posting integration.

The six requested module suites passed 369 tests, but their success does not establish this missing control. No production data, live PostgreSQL, distributed fault injection or production load testing was used for this audit. A remediation must supply the relevant additional evidence before this issue is closed.
