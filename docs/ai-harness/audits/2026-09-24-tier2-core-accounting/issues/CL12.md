## Problem statement

The annual service collects all summaries and every posted detail into memory. Each journal triggers detail lookup, and detail mapping performs historical master lookup. Remote deployment multiplies service calls.

## Reproduction / evidence

Static source establishes O(annual journal/detail volume) materialization and repeated lookups. A source TODO acknowledges provider-side aggregation and 100M-row validation remain undone. No load benchmark was run.

Evidence level: source and call-path analysis. The described failure schedule is a reproduction plan unless explicitly identified as executed above.

## Financial / architectural impact

Annual closing can exhaust memory or exceed transaction/service timeouts at enterprise volume.

## Proposed solution

Provide a stable-cutoff, base-currency aggregate query grouped by dated account classification, with bounded streaming where aggregation cannot be delegated.
