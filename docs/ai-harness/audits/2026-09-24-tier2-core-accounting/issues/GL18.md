## Problem statement

If rule selection returns Optional.empty, the listener logs a warning and returns normally. Its exception-based failure mechanism is not invoked and no unresolved-work record is persisted.

## Reproduction / evidence

Static reproduction: send an otherwise valid event for which no rule exists or is currently active. The listener returns successfully without a journal. Broker/container acknowledgement was not exercised; under ordinary successful listener processing this is consumed work.

Evidence level: source and call-path analysis. The described failure schedule is a reproduction plan unless explicitly identified as executed above.

## Financial / architectural impact

Source economic events can be omitted from the ledger without a durable completeness exception to reconcile or replay.

## Proposed solution

Persist unmatched events in a durable quarantine/reconciliation workflow or fail into an explicitly configured recovery policy. A warning is not a financial disposition.
