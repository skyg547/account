## Problem statement

An event without accountingDate is assigned LocalDate.now rather than rejected or resolved from immutable event evidence.

## Reproduction / evidence

Static reproduction: redeliver the same undated event on opposite sides of month end. Journal creation receives different accounting dates; current-period OPEN validation can accept a transaction whose actual event period is closed.

Evidence level: source and call-path analysis. The described failure schedule is a reproduction plan unless explicitly identified as executed above.

## Financial / architectural impact

Processing delays and retries can shift financial recognition and cutoff without an explicit operator decision.

## Proposed solution

Require a validated accounting date or an immutable source-event date under a documented policy; quarantine incomplete events.
