# 🎨 [Tech 27] Tailwind CSS

### 👶 초보자를 위한 개념 설명
> **Tailwind CSS란 무엇인가요?**
> 마치 **"미리 준비된 옷(기성복)들이 가득한 편집샵"**과 같습니다. 예전에는 옷을 직접 디자인하고 원단을 끊어서 만들어야 했지만(Vanilla CSS), Tailwind는 "파란색 셔츠", "라지 사이즈", "둥근 소매"라는 이름의 이름표(Class)만 붙이면 즉시 옷이 입혀지는 유틸리티 중심의 스타일 도구입니다.

### 💡 주요 특징 및 예시
1. **Utility-First**: `flex`, `pt-4`, `text-blue-500` 같은 짧은 단어로 디자인을 끝냅니다.
2. **Design Consistency**: 정해진 규격 안에서 쓰기 때문에 디자인이 중구난방이 되지 않고 깔끔해집니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[버튼 디자인 입히기]**
1. **코드 작성**: HTML 태그의 `className`에 원하는 스타일을 적습니다.
   ```tsx
   <button className="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
     클릭하세요
   </button>
   ```
2. **결과 확인**: 저장 즉시 파란색 배경과 둥근 모서리가 적용됩니다.
3. **확장**: `dark:bg-slate-900` 처럼 한 단어만 추가하면 다크모드 대응도 끝납니다.

# 📦 [Tech 28] H2 Database

### 👶 초보자를 위한 개념 설명
> **H2 Database란 무엇인가요?**
> 마치 **"휴대하기 편한 초소형 미니 냉장고"**와 같습니다. 원래 냉장고(Oracle, MySQL)는 크고 무거워서 설치가 힘들지만, H2는 가볍고 빨라서 개발자가 내 컴퓨터에서 테스트용 자료를 잠시 보관할 때 아주 요긴하게 쓰입니다.

### 💡 주요 특징 및 예시
1. **In-Memory**: 메모리에만 저장해서 서버를 끄면 데이터가 사라지지만, 대신 엄청나게 빠릅니다. (개발/테스트용)
2. **Zero Setup**: 복잡한 설치 없이 자바 프로젝트 안에 바로 심어서 쓸 수 있습니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[개발용 데이터베이스 사용하기]**
1. **설정 확인**: `application.yml` 파일에서 `jdbc:h2:mem:testdb` 주소를 확인합니다.
2. **콘솔 접속**: 브라우저에서 `/h2-console` 주소로 접속합니다.
3. **테이블 확인**: 내가 만든 엔티티가 테이블로 잘 만들어졌는지 SQL을 직접 날려 확인해 봅니다.
