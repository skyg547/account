# 🌊 [Tech 31] Java Stream API

### 👶 초보자를 위한 개념 설명
> **Java Stream이란 무엇인가요?**
> 마치 **"공장의 자동화 컨베이어 벨트"**와 같습니다. 수많은 원재료(데이터 리스트)를 하나하나 손으로 집어 옮기지 않고, 벨트 위에 올려두면 필터기(Filter)가 불량품을 걸러내고 조립기(Map)가 부품을 끼워 넣어서 최종 제품(결과물)을 만들어냅니다.

### 💡 주요 특징 및 예시
1. **Declarative**: "이 데이터를 어떻게 처리해라"라고 명령만 내리면 복잡한 반복문 없이 한 줄로 끝납니다.
2. **Immutability**: 원본 데이터를 건드리지 않고 새로운 결과를 만들어내므로 안전합니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[리스트에서 특정 조건만 골라내기]**
1. **스트림 열기**: `myList.stream()`으로 컨베이어 벨트를 가동합니다.
2. **필터링**: `.filter(x -> x.getAmount() > 1000)`으로 비싼 전표만 남깁니다.
3. **변환**: `.map(x -> x.getTitle())`으로 제목만 쏙쏙 뽑습니다.
4. **결과 수집**: `.toList()`로 최종 바구니에 담습니다.

# 🤝 [Tech 32] Spring Cloud Contract

### 👶 초보자를 위한 개념 설명
> **무엇인가요?**
> 마치 **"공증받은 법적 계약서"**와 같습니다. A팀과 B팀이 "앞으로 우리는 이런 형식의 데이터를 주고받자"라고 미리 약속을 하고 계약서를 써둡니다. 만약 개발 중에 누군가 실수로 약속을 어기면(데이터 형식 변경), 시스템이 "계약 위반입니다!"라고 알려주어 사고를 막아줍니다.

### 💡 주요 특징 및 예시
1. **Consumer-Driven Contracts**: 데이터를 받는 쪽의 기준에 맞춰 약속을 정합니다.
2. **Stub Runner**: 실제 서버를 켜지 않아도 약속된 가짜 데이터(Stub)를 주고받으며 테스트할 수 있게 해줍니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[API 약속 지키기]**
1. **계약서 작성**: Groovy나 YAML 형식으로 "이 주소로 요청하면 이런 데이터를 줘"라고 적습니다.
2. **테스트 생성**: 빌드 시 자동으로 이 계약이 유효한지 검증하는 코드가 생성됩니다.
3. **배포 승인**: 테스트를 통과해야만 실제 서버에 배포될 자격이 주어집니다.
