# 📈 [Tech 33] Recharts

### 👶 초보자를 위한 개념 설명
> **Recharts란 무엇인가요?**
> 마치 **"엑셀 그래프의 웹 버전"**과 같습니다. 복잡한 숫자 더미를 막대그래프, 선그래프, 파이차트로 변환하여 한눈에 데이터의 흐름(예: 대손충당금 지표, 매출 현황)을 파악할 수 있게 해주는 시각화 도구입니다.

### 💡 주요 특징 및 예시
1. **Composable**: `<Line />`, `<XAxis />` 처럼 작은 부품들을 조립해서 그래프를 만듭니다.
2. **Responsive**: 화면 크기에 맞춰 그래프 크기가 자동으로 조절됩니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[간단한 선 그래프(Line Chart) 그리기]**
1. **데이터 준비**: `[{ name: '1월', value: 400 }, ...]` 형식의 배열을 만듭니다.
2. **컴포넌트 조립**:
   ```tsx
   <LineChart width={400} height={400} data={data}>
     <XAxis dataKey="name" />
     <Line type="monotone" dataKey="value" stroke="#8884d8" />
   </LineChart>
   ```
3. **확장**: 마우스를 올렸을 때 숫자가 보이는 `Tooltip`을 추가하여 가독성을 높입니다.

# 🛡️ [Tech 34] Spring AOP (Aspect Oriented Programming)

### 👶 초보자를 위한 개념 설명
> **AOP란 무엇인가요?**
> 마치 **"건물 전체에 설치된 화재 감지기 및 CCTV"**와 같습니다. 각 방(메서드)마다 감지기를 따로 설치할 필요 없이, 건물 전체에 규칙을 정해두면 불(에러)이 나거나 사람(요청)이 들어올 때 자동으로 작동하여 로그를 남기거나 보안을 검사합니다.

### 💡 주요 특징 및 예시
1. **Cross-cutting Concerns**: 로깅, 트랜잭션, 보안 등 여러 곳에 공통으로 쓰이는 코드를 한 곳에서 관리합니다.
2. **Proxy**: 실제 비즈니스 로직 앞뒤에 부가적인 기능을 몰래 실행해 줍니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[모든 서비스 실행 시간 기록하기]**
1. **Aspect 정의**: `@Aspect` 어노테이션을 붙인 클래스를 만듭니다.
2. **Pointcut 설정**: `@Around("execution(* com.ho..service.*.*(..))")` 처럼 감시할 범위를 정합니다.
3. **로직 작성**: 메서드 호출 전후의 시간을 측정하여 로그를 남깁니다.

# ⚓ [Tech 35] Spring Validation (Hibernate Validator)

### 👶 초보자를 위한 개념 설명
> **Validation이란 무엇인가요?**
> 마치 **"공항의 입국 심사대"**와 같습니다. 데이터베이스에 들어가기 전, "이름이 비어있지는 않은지", "금액이 마이너스는 아닌지" 꼼꼼하게 검사하여 불량 데이터가 시스템을 망가뜨리지 못하게 막습니다.

### 💡 주요 특징 및 예시
1. **Annotation 기반**: `@NotBlank`, `@Min(0)`, `@Email` 등 한 줄로 복잡한 검사 로직을 대신합니다.
2. **Message Customization**: "금액은 0원보다 커야 합니다"와 같이 친절한 안내 문구를 설정할 수 있습니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[전표 입력 데이터 검증하기]**
1. **DTO 설정**: 변수 위에 `@NotNull` 등을 붙입니다.
   ```java
   @Min(value = 100, message = "전표 최소 금액은 100원입니다.")
   private BigDecimal amount;
   ```
2. **Controller 적용**: 파라미터 앞에 `@Valid`를 붙여 심사를 시작합니다.
3. **예외 처리**: 검사에 탈락하면 즉시 에러 응답을 보내 사용자에게 수정을 요청합니다.
