# 📮 [Tech 09] Apache Kafka (Message Broker)

### 👶 초보자를 위한 개념 설명
> **Kafka란 무엇인가요?**
> 마치 **"전 세계에서 가장 빠르고 튼튼한 거대 우체국"**과 같습니다. 수많은 서비스가 서로 편지를 보내려 할 때, 중간에서 잃어버리지 않게 차곡차곡 쌓아두고 받는 쪽이 원할 때 언제든지 꺼내 갈 수 있게 해주는 거대한 소통 창구입니다.

### 💡 주요 특징 및 예시
1. **Asynchronous**: 보낸 사람이 받는 사람의 대답을 기다리지 않고 바로 다음 일을 할 수 있게 해줍니다. (속도 향상)
2. **Durability**: 서버가 잠시 꺼져도 보관된 메시지는 사라지지 않고 안전하게 유지됩니다.

### 🛠️ 우리 프로젝트에서의 활용
- **Service Sync**: 예를 들어 `asset-lease` 서비스에서 리스료를 계산하면, Kafka를 통해 `journal-ledger` 서비스로 "전표를 끊어라!"라고 외칩니다. 두 서비스가 직접 연결되지 않아도 완벽하게 소통합니다.

# 🛰️ [Tech 10] Eureka & Spring Cloud Config

### 👶 초보자를 위한 개념 설명
> **Eureka와 Config가 무엇인가요?**
> - **Eureka**: 수많은 마이크로서비스들이 등록된 **"통합 전화번호부"**입니다. 서비스가 늘어나도 누가 어디 있는지 바로 찾아줍니다.
> - **Spring Cloud Config**: 수많은 서비스의 설정값(비밀번호, 주소 등)을 한 곳에서 관리하는 **"중앙 통제실"**입니다.

### 💡 주요 특징 및 예시
1. **Service Discovery (Eureka)**: 서비스가 새로 생기면 Eureka에 "나 여기 있어!"라고 등록합니다. 다른 서비스는 Eureka를 보고 전화를 겁니다. 
2. **Centralized Management (Config)**: 각 서비스마다 설정 파일을 두지 않고, 중앙에서 관리하므로 설정 하나만 바꾸면 모든 서비스가 동시에 적용됩니다.

### 🛠️ 우리 프로젝트에서의 활용
- **MSA 운영**: 우리 시스템이 10개, 100개로 쪼개져도 관리자가 혼란스럽지 않게 인프라를 지탱해주는 뼈대 역할을 합니다.
