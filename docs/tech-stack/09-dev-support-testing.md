# 📝 [Tech 21] TypeScript

### 👶 초보자를 위한 개념 설명
> **TypeScript란 무엇인가요?**
> 마치 **"안전장치가 달린 전동 드릴"**과 같습니다. 원래 JavaScript는 너무 자유로워서 구멍을 뚫다가 실수로 손을 다칠 수(런타임 에러)도 있는데, TypeScript는 미리 "여기는 나무니까 이 정도 힘만 써!"라고 알려주어 사고를 방지해줍니다.

### 💡 주요 특징 및 예시
1. **Static Typing**: 변수가 숫자인지 글자인지 명확히 정해줍니다.
2. **IDE Support**: 코드를 칠 때 다음에 뭘 써야 할지 아주 정확하게 추천해줍니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[타입 안전하게 컴포넌트 만들기]**
1. **인터페이스 정의**: 컴포넌트가 받을 데이터의 형식을 정합니다.
   ```typescript
   interface UserProps { name: string; age: number; }
   ```
2. **컴포넌트에 적용**: `(props: UserProps)` 처럼 타입을 명시합니다.
3. **사용**: 다른 곳에서 이 컴포넌트를 쓸 때 숫자가 들어갈 자리에 글자를 넣으면 즉시 빨간 줄이 뜨며 경고합니다.

# 🌶️ [Tech 22] Lombok

### 👶 초보자를 위한 개념 설명
> **Lombok이란 무엇인가요?**
> 마치 **"자동 청소 로봇"**과 같습니다. Java 코드를 짤 때 매번 만들어야 하는 지루한 코드들(getter, setter, 생성자 등)을 대신 자동으로 청소하고 채워주어 개발자가 핵심 비즈니스 로직에만 집중하게 해줍니다.

### 💡 주요 특징 및 예시
1. **Annotation 기반**: `@Getter`, `@Setter`, `@Builder` 하나로 수십 줄의 코드를 대체합니다.
2. **Clean Code**: 파일 크기가 줄어들어 코드가 훨씬 읽기 편해집니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[지루한 코드 자동 생성하기]**
1. **어노테이션 추가**: 클래스 위에 `@Data`나 `@NoArgsConstructor`를 붙입니다.
2. **코드 확인**: 직접 타이핑하지 않아도 외부에서 `.getName()` 등을 바로 사용할 수 있습니다.
3. **객체 생성**: 폼이 많은 객체는 `@Builder`를 써서 `User.builder().name("A").build()` 처럼 우아하게 생성합니다.

# 🧪 [Tech 23] JUnit 5 & Mockito

### 👶 초보자를 위한 개념 설명
> **JUnit과 Mockito란 무엇인가요?**
> - **JUnit**: 우리 코드가 정상인지 검사하는 **"현장 감찰관"**입니다.
> - **Mockito**: 테스트를 위해 가짜 상황을 만들어주는 **"연기자(스턴트 대역)"**입니다. DB가 없어도 DB가 있는 척 연기해서 로직을 테스트하게 해줍니다.

### 💡 주요 특징 및 예시
1. **Assertion**: `assertEquals(expected, actual)`를 통해 결과가 내 예상과 같은지 확인합니다.
2. **Stubbing**: "이 함수가 불리면 무조건 '성공'이라고 대답해"라고 연기자(Mock)에게 미리 시킵니다.

### 🚀 실전 사용 가이드 (Step-by-Step)
**[테스트 코드 작성하기]**
1. **테스트 클래스 생성**: `@Test` 어노테이션이 붙은 메서드를 만듭니다.
2. **Mock 설정**: `@Mock`으로 가짜 객체를 만들고 `when(...).thenReturn(...)`으로 행동을 정합니다.
3. **실행 및 검증**: 로직을 돌린 후 `verify(...)`로 로직이 제대로 작동했는지 검사합니다.
