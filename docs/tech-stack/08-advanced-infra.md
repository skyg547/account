# 🏗️ [Tech 16] Flyway (DB Versioning)

### 👶 초보자를 위한 개념 설명
> **Flyway란 무엇인가요?**
> 마치 **"건축 설계도(Blueprints)의 히스토리북"**과 같습니다. 건물을 짓다가 "아, 여기에 기둥 하나 더 세울걸" 하고 설계도를 고칠 때마다, 이전 도면부터 최신 도면까지 순서대로 기록해서 누가 언제 고쳤는지 알 수 있게 하고, 모든 일꾼이 똑같은 최신 도면을 보고 일하게 해줍니다.

### 💡 주요 특징 및 예시
1. **Migration**: `V1__create_table.sql`, `V2__add_column.sql` 처럼 번호를 붙여 관리하므로, 어떤 컴퓨터에서나 똑같은 DB 구조를 만들 수 있습니다.
2. **Safety**: 예전에는 실수로 DB를 다 날려버리기도 했지만, Flyway를 쓰면 안전하고 체계적으로 DB 구조를 변경할 수 있습니다.

# 🚀 [Tech 17] Redis (In-memory & Distributed Lock)

### 👶 초보자를 위한 개념 설명
> **Redis란 무엇인가요?**
> 마치 **"가장 자주 쓰는 포스트잇 화이트보드"**와 같습니다. 원래 책상 서랍(DB)을 열어서 찾는 건 시간이 걸리지만, 화이트보드(Redis)에 적어두면 0.001초 만에 볼 수 있습니다. 또한, "이 물건은 내가 만지는 중이야!" 하고 자물쇠를 걸어두는 역할(Distributed Lock)도 합니다.

### 💡 주요 특징 및 예시
1. **Cache**: 환율 정보나 마스크 데이터처럼 수시로 조회되는 정보는 Redis에 담아두어 시스템 속도를 비약적으로 높입니다.
2. **Concurrency Control**: 아주 짧은 순간에 "전표 승인" 버튼을 두 번 눌렀을 때, 고성능 자물쇠 역할을 하여 중복 승인 대참사를 막아줍니다.

# 🔒 [Tech 18] HashiCorp Vault

### 👶 초보자를 위한 개념 설명
> **Vault란 무엇인가요?**
> 마치 **"최첨단 스위스 은행 비밀 금고"**와 같습니다. 우리 시스템의 아주 중요한 비밀정보(디비 비밀번호, 암호화 키 등)를 소스코드나 파일에 적어두지 않고, 이 철통보안 금고 안에 숨겨둡니다.

# 📞 [Tech 19] OpenFeign

### 👶 초보자를 위한 개념 설명
> **OpenFeign이란 무엇인가요?**
> 마치 **"다이얼 버튼만 누르면 되는 스마트 사내 전화기"**와 같습니다. 옆 부서(다른 서비스)에 요청을 보낼 때, 어려운 HTTP 주소나 세팅을 할 필요 없이 자바 코드 한 줄로 아주 우아하게 전화를 걸어 데이터를 주고받을 수 있게 해줍니다.

# 📖 [Tech 20] Swagger / OpenAPI

### 👶 초보자를 위한 개념 설명
> **Swagger란 무엇인가요?**
> 마치 **"식당의 사진이 포함된 통합 메뉴판"**과 같습니다. 프론트엔드 개발자가 백엔드에게 "이 데이터 어떻게 가져와요?"라고 물어볼 필요 없이, 웹사이트 주소만 치면 모든 API의 상세 정보와 테스트 버튼이 담긴 예쁜 웹페이지가 자동으로 나타납니다.
