# 📦 Zipkin (집킨) - "MSA 운송장 배송 조회 시스템 (분산 추적)"

## 1. 초보자를 위한 개념 설명
사용자가 웹사이트에서 "전표 조회" 버튼을 한 번 눌렀는데, 이 요청이 `A서버 -> B서버 -> C서버`를 거쳐가다가 에러가 났다고 생각해 보세요. ELK에 수많은 에러 로그가 쌓여있지만, 도대체 **어떤 사용자의 어떤 클릭 때문에** 연쇄적으로 터진 에러인지 찾기가 모래사장에서 바늘 찾기입니다.

**Zipkin**은 사용자의 최초 요청에 **'운송장 번호(Trace ID)'**를 딱 하나 발급해서 끝까지 꼬리표처럼 달고 다니게 합니다.
나중에 집킨 웹 화면에서 운송장 번호만 검색하면, **"A서버에서 0.5초, B서버에서 1.2초 걸렸고, C서버에서 DB 연결 에러가 났음"**을 예쁜 막대그래프(Waterfall)로 한눈에 보여주는 마법의 배송 조회 센터입니다!

## 2. 이 폴더의 역할
- `docker-compose.yml`: 집킨 서버(배송 조회 센터)를 띄우기 위한 스크립트입니다. 내장된 메모리 DB를 사용하므로 매우 가볍습니다.

## 3. 실행 및 확인 방법
- MSA 철학에 따라, 이 모듈은 **독자적인 `docker-compose.yml`**을 가집니다.

### ⚠️ 필수 선행 작업
이전에 실행했던 프로젝트 최상단의 `setup-network.bat`를 통해 `account-network`가 이미 만들어져 있어야 합니다.

### 🚀 실행 순서
1. 터미널을 열고 **`zipkin` 폴더 안으로 이동**합니다. (`cd zipkin`)
2. 아래 명령어를 실행합니다:
   ```bash
   docker-compose up -d
   ```
3. 브라우저에서 [http://localhost:9411](http://localhost:9411) 에 접속하면 돋보기가 있는 집킨 검색 화면이 나옵니다.
4. 이제 Spring Boot 서비스들이 서로 API 통신을 할 때마다 집킨 화면의 돋보기(Run Query)를 누르면 요청의 궤적이 그려집니다!
