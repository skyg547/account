# 대외 보고서(External Reporting) 핵심 기능 및 처리 과정 분석

## 1. 개요
대외 보고서는 주주, 투자자, 금융감독원 등 외부 이해관계자에게 제공되는 공식적인 재무 기록입니다. 단순한 합계를 넘어 '비교 가능성'과 '투명성'이 최우선입니다.

## 2. 필수 핵심 기능
* **비교 재무제표(Comparative Statements)**: 당기(Current Period)뿐만 아니라 전기(Previous Period) 데이터를 나란히 표시하여 성과 변화를 보여줘야 합니다.
* **주석 연동(Note Linkage)**: 재무제표의 특정 항목(예: 매출채권)에 대해 상세 내역(연령 분석, 대손충당금 등)을 설명하는 주석 번호를 매핑해야 합니다.
* **재무지표 산출(Financial Ratios)**: 유동비율, 부채비율 등 보고서 사용자가 즉시 활용할 수 있는 주요 지표를 자동 계산합니다.
* **통합 원장 대조(Reconciliation)**: 보고서 금액이 원장(G/L)의 합계와 일치하는지 최종 검증하는 '보고서 정합성 체크' 기능이 필수입니다.

## 3. 보고서 생성 처리 과정 (Processing Flow)

### [Phase 1: 데이터 추출 (Extraction)]
1. **기준일 확정**: 보고 대상 기간의 마감 상태를 확인합니다.
2. **원장 데이터 로드**: `journal-ledger`에서 계정별 잔액을 가져옵니다.
3. **비교 데이터 로드**: 작년 동기의 확정된 보고서 데이터를 불러옵니다.

### [Phase 2: 매핑 및 분류 (Classification)]
1. **계정과목 매핑**: 내부 관리용 계정과목을 대외 공시용 표준 항목(예: '현금' + '당좌예금' -> '현금 및 현금성자산')으로 그룹화합니다.
2. **주석 번호 할당**: 각 항목에 해당하는 주석 코드(Note ID)를 연결합니다.

### [Phase 3: 계산 및 검증 (Calculation & Validation)]
1. **소계 및 합계 계산**: 자산총계, 부채총계 등을 산출합니다.
2. **정합성 체크**: 자산 = 부채 + 자본 등식이 성립하는지 검증합니다. 만약 차이가 발생하면 '검토 필요' 알람을 발생시킵니다.

### [Phase 4: 확정 및 공시 (Finalization)]
1. **보고서 스냅샷 저장**: 확정된 시점의 데이터를 보존합니다.
2. **출력물 생성**: PDF 또는 전자공시용(XBRL) 파일로 변환 가능한 상태로 준비합니다.
