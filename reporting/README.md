# Reporting Module (대외 보고서 관리 모듈)

## 1. 모듈 개요
본 모듈은 시스템의 핵심 데이터인 총계정원장(Journal Ledger)을 기반으로, 대외 공시용 재무제표(Financial Statements)와 필수 주석(Disclosure Notes)을 산출하는 역할을 담당합니다.

### 초보자를 위한 개념 설명
* **재무제표(Financial Statements)**: 은행이나 기업의 성적표입니다. "얼마나 벌었는지(손익계산서)", "현재 재산이 얼마인지(재무상태표)"를 보여줍니다.
* **주석(Notes)**: 성적표에 붙는 상세 설명입니다. 예를 들어, "빌려준 돈 100억 중 10억은 못 받을 것 같아서 따로 떼어놨습니다" 같은 구체적인 정보를 기록합니다.
* **원장(Ledger)**: 모든 거래 내역이 적힌 장부입니다. 보고서는 이 장부의 숫자들을 합쳐서 만듭니다.

## 2. 아키텍처 구조 (Hexagonal Architecture)
본 모듈은 내부 비즈니스 로직을 외부 기술(DB, API)로부터 분리하는 헥사고날 아키텍처를 따릅니다.

* **api**: 외부(웹 브라우저 등)에서 보고서 조회를 요청할 때 사용하는 접점입니다.
* **batch**: 데이터가 너무 많을 때 밤사이에 미리 보고서를 만들어두는 '일괄 처리' 담당입니다.
* **core**: 보고서를 만드는 '진짜 규칙'이 들어있는 핵심부입니다.
    * **domain**: 보고서, 항목 등 핵심 데이터 모델과 수식입니다.
    * **application**: "원장에서 데이터를 가져와서 보고서를 만든다"는 전체 흐름을 관리합니다.
    * **infrastructure**: 실제로 DB에 저장하거나 다른 모듈(원장)에서 데이터를 가져오는 기술적 구현체입니다.

## 3. 주요 비즈니스 흐름
1. 사용자가 특정 기간(예: 2026년 1분기)의 재무상태표 생성을 요청합니다.
2. `core`는 `journal-ledger` 모듈에 해당 기간의 계정별 잔액을 요청합니다.
3. 가져온 잔액들을 표준 재무제표 양식에 맞춰 합산(Aggregation)합니다.
4. 산출된 결과와 함께 필요한 주석 정보를 결합하여 최종 보고서를 생성합니다.
