# 🚒 프론트엔드 런북 (장애 해결 및 문제 대응 가이드)

프로그램이 안 돌아가거나 에러가 날 때 당황하지 말고 여기를 먼저 봐주세요!

---

## 1. 서버가 안 켜져요! (Port 3000 Conflict)
*   **증상**: `address already in use :::3000` 이런 메시지가 나옵니다.
*   **원인**: 다른 인터넷 창이나 예전에 켜둔 프로그램이 3000번 포트를 이미 쓰고 있는 거예요.
*   **해결 방법**:
    1. 터미널 창을 모두 닫고 다시 켜보세요.
    2. 그래도 안 되면 컴퓨터를 껐다 켜거나, `lsof -i :3000` (Mac/Linux) 또는 `netstat -ano | findstr :3000` (Windows) 명령어로 해당 프로그램을 찾아 종료해야 합니다.

---

## 2. 화면이 하얗게만 나와요! (Blank Page)
*   **증상**: 아무 에러도 없는데 화면에 아무것도 안 보입니다.
*   **해결 방법**:
    1. 개발자 도구(`F12`)를 눌러서 `Console` 탭에 빨간색 에러 메시지가 있는지 확인하세요.
    2. `.next` 폴더를 삭제하고 다시 `npm run dev`를 실행해 보세요. (다시 집을 짓는 과정입니다.)

---

## 3. 새로운 라이브러리를 설치하고 싶어요!
*   **해결 방법**:
    1. 꼭 필요한 것인지 팀장님(`[기획/팀장]`)께 먼저 물어봐 주세요.
    2. 승인이 나면 `npm install 패키지이름` 명령어를 사용합니다.
    3. 설치 후에는 반드시 `package.json`에 잘 들어갔는지 확인하세요.

---

## 4. 빌드 오류가 나요! (`npm run build` 실패)
*   **원인**: 타입스크립트(`TypeScript`)가 엄격하게 검사하기 때문입니다.
*   **해결 방법**:
    1. 에러 메시지에 적힌 파일명과 줄 번호를 확인하세요.
    2. 오타가 있거나, 변수 이름이 틀렸거나, 값이 없을 수도 있는데 쓰려고 할 때 자주 발생합니다.
    3. "조금 더 꼼꼼하게 코드를 짜야 해!"라는 신호이니 차분하게 고쳐보세요.
