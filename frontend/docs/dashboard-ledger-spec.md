# 대시보드(Dashboard) & 원장관리(Ledger) 도메인 설계서

> **Issue**: #9
> **브랜치**: `feature/frontend-ui-update`

## 1. 개요
전사 통합 대시보드 화면 1개와 회계의 핵심인 원장관리(전표 작성, 전표 조회, 총계정원장, 보조원장, 분개 규칙, 미결항목 정리) 화면 6개를 정의하는 설계서입니다.

## 2. 화면 목록

### 2.1. 대시보드 (DASHBOARD)
| 경로 | 화면 구성 및 주요 컴포넌트 |
|---|---|
| `/` | 상단 주요 KPI (자산/부채/당기순이익/수익/비용), 하단 좌측 볼륨 차트(리차트), 하단 우측 최근 전표 피드 |

### 2.2. 원장관리 (LEDGER)
| 경로 | 화면 구성 및 주요 컴포넌트 |
|---|---|
| `/ledger/entry` | 전표 마스터(Header) 영역과 차/대 라인 아이템(Grid) 입력 영역, 대차 차액 검증, 임시저장/상신 버튼 |
| `/ledger/list` | 기간, 부서, 상태(작성중/결재중/승인/반려) 필터링이 포함된 전표 목록, 상세 내용 모달 |
| `/ledger/gl` | 총계정원장. 계정별 이월잔액, 차/대 발생액, 기말잔액 요약 집계표 및 검색바 |
| `/ledger/sl` | 보조원장. 특정 계정에 속한 거래처별/부서별 상세 잔액 내역 표출 |
| `/ledger/rules` | 자동 분개 규칙 설정. 이벤트 소스(수납, 대출실행 등)와 차/대 계정 매핑 룰 그리드 |
| `/ledger/unsettled` | 미결항목 정리. 채권/채무 미결 항목과 반대 분개 항목을 선택하여 상계(Clearing) 처리하는 UI |
