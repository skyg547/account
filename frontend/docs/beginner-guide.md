# 🐣 프론트엔드 초보자 가이드 (KBank 핀테크 디자인 & 아키텍처)

환영합니다! **Account.AI 차세대 재무회계 및 자산운용 플랫폼** 프론트엔드 개발팀에 오신 것을 환영합니다.  
이 문서는 프론트엔드나 Next.js가 처음인 개발자도 시스템 구조를 쉽게 이해하고 바로 기여할 수 있도록 작성되었습니다.

---

## 1. 🏗️ 우리 시스템의 기술 스택 (기술 뼈대)

우리 프론트엔드는 현대적이고 빠르며 안전한 최신 표준 스택을 채택하고 있습니다.

| 기술 | 역할 | 설명 |
| :--- | :--- | :--- |
| **Next.js 15 (App Router)** | 웹 프레임워크 | 페이지 라우팅, 서버 컴포넌트, 정적 페이지 빌드(122개 라우트)를 총괄합니다. |
| **React 19** | UI 라이브러리 | 레고 블록처럼 독립적인 UI 컴포넌트를 조립하여 화면을 만듭니다. |
| **Tailwind CSS v4** | 스타일링 엔진 | 별도 CSS 파일 작성 없이 유틸리티 클래스로 반응형 핀테크 디자인을 완성합니다. |
| **Lucide React** | 아이콘 라이브러리 | 일관된 두께와 세련된 벡터 아이콘을 제공합니다. |
| **Recharts** | 금융 차트 | 자산/부채 추이, 수지 분석 등 실시간 금융 데이터를 미려한 차트로 시각화합니다. |

## 2. 📁 폴더 구조 한눈에 보기

```
frontend/
├── src/
│   ├── app/                 # 🌐 [페이지 라우터] 주소(URL)와 매핑되는 122개 화면
│   │   ├── layout.tsx       # 전체 화면을 감싸는 최상위 껍데기 (ThemeProvider, NavProvider)
│   │   ├── page.tsx         # 메인 대시보드 화면 (통합 재무 현황)
│   │   ├── login/           # 통합 인증 및 로그인 (SSO, LDAP + OTP)
│   │   ├── expenditure/     # 자금운영 (지출결의서, 지급실행, 선급금, 예산)
│   │   ├── ledger/          # 원장 및 분개장 (총계정원장, 보조원장, 분개규칙)
│   │   ├── fair-value/      # 공정가치 및 리스 회계 (IFRS 16, 감가상각)
│   │   └── system/          # 시스템 관리 (사용자, 역할, 메뉴 권한)
│   ├── components/          # 🧩 [재사용 부품]
│   │   ├── layout/          # 공통 레이아웃 (Sidebar, TopHeader, Footer, MainLayout)
│   │   └── ui/              # 범용 UI 부품 (PageHeader, StatusBadge, AmountDisplay, Tabs 등)
│   ├── context/             # 🧠 [글로벌 상태 관리]
│   │   ├── ThemeContext.tsx # ☀️/🌙 라이트/다크 테마 전환 및 영속화
│   │   └── NavContext.tsx   # 7대 카테고리 네비게이션 & RBAC 권한 필터링
│   ├── services/            # 🔌 [API 통신 & Mock Fallback] 백엔드 연동 서비스 레이어
│   └── mocks/               # 📦 [모의 데이터] 백엔드 오프라인 시 동작하는 안전한 데이터셋
```

## 3. 🎨 케이뱅크(KBank) 핀테크 디자인 시스템

우리 UI는 **케이뱅크(K-Bank) 특유의 신뢰감 있고 산뜻한 금융 디자인**을 계승합니다.

1. **캔버스 & 카드 레이어**:
   * **라이트 모드**: 소프트 그레이(`#f7f8fb`) 캔버스 위에 맑은 **퓨어 화이트 카드(`#ffffff`)**와 은은한 테두리(`#eaedf4`)
   * **다크 모드**: 눈이 편안한 딥 네이비 캔버스(`#0b0f19`) 위에 **슬레이트 카드(`#131b2e`)**
2. **시그니처 컬러**:
   * **KBank Blue (`#4262ff`)**: 주요 액션 버튼, 활성 탭, 브랜드 포인트
   * **Success Green (`#10b981`)**: 확정 전표, 승인 완료, 자산 증가
   * **Warning Amber (`#f59e0b`)**: 결재 대기, 미결 건, 주의 알림
   * **Danger Rose (`#f43f5e`)**: 반려, 부채, 연체 경고
3. **금융 정밀 타이포그래피**:
   * 폰트: `Pretendard`, `Inter` (한글/영문 가독성 최적화)
   * 자간: **`-0.015em`** (숫자와 텍스트가 정갈하게 정렬)
   * 금액 표기: `<AmountDisplay amount={15000000} />` 컴포넌트를 사용하여 항상 천 단위 콤마와 `₩` 통화 기호를 정밀하게 표시합니다.

## 4. 🛡️ 장애 복원력 (Offline Mock Fallback)

우리 프론트엔드는 **백엔드 서버(Java/Spring Boot)가 꺼져 있어도 122개 전체 페이지가 100% 정상 작동**하도록 설계되었습니다.
* API 호출 시 1.5초 이내에 백엔드 응답이 없으면 사전에 준비된 `mocks/` 데이터로 자동 전환됩니다.
* 따라서 백엔드 환경이 준비되지 않은 상태에서도 프론트엔드 단독으로 화면 개발 및 디자인 검수를 자유롭게 수행할 수 있습니다.
