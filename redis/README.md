# 🚀 Redis (레디스) - "초고속 분산 캐시 및 화이트보드"

## 1. 초보자를 위한 개념 설명
매번 무거운 DB(도서관 지하창고)까지 내려가서 데이터를 찾아오면 너무 느립니다. 
**Redis**는 도서관 데스크 위에 놓인 **'초고속 화이트보드'**입니다.

- **캐시(Cache):** 계정과목(`master-data`)처럼 잘 안 변하고 자주 찾는 정보는 이 화이트보드에 적어두고 0.01초 만에 꺼내갑니다.
- **분산 락(자물쇠):** 사용자가 '결제' 버튼을 마우스로 따닥! 두 번 누르면 전표가 2장 생기는 끔찍한 사고가 날 수 있습니다. 서버 10대가 동시에 요청을 받아도, 화이트보드에 "지금 내가 처리 중이니까 아무도 건들지 마!" 라고 **단 하나의 자물쇠**를 걸어두어 동시성 문제를 완벽히 해결합니다.

## 2. 실행 및 확인 방법
- MSA 철학에 따라, 이 모듈은 **독자적인 `docker-compose.yml`**을 가집니다.

### ⚠️ 필수 선행 작업
이전에 실행했던 프로젝트 최상단의 `setup-network.bat`를 통해 `account-network`가 이미 만들어져 있어야 합니다.

### 🚀 실행 순서
1. 터미널을 열고 **`redis` 폴더 안으로 이동**합니다. (`cd redis`)
2. 아래 명령어를 실행합니다:
   ```bash
   docker-compose up -d
   ```
3. 브라우저에서 [http://localhost:8081](http://localhost:8081) 에 접속합니다! (Redis Commander 관리자 화면)
4. 화이트보드에 어떤 데이터가 적히는지 눈으로 직접 확인할 수 있습니다.
