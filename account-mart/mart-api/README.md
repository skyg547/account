# 📞 리스크 마트 API 모듈 (mart-api)

> **Role**: [백엔드 개발자]
> **Metaphor**: [고객 응대 창구]

## 💡 초보자를 위한 개념 설명
본 모듈은 리스크 데이터 저장소의 **'출고 창구'**입니다.
- **데이터 제공**: ETL 공장(Batch)에서 깨끗하게 닦아서 저장해둔 통합 리스크 데이터(CDM)와 시장 데이터(환율, 금리 등)를 리스크 엔진이나 대시보드가 쓸 수 있게 API로 내보냅니다.
- **정합성 확인**: 외부에서 들어온 데이터 조회 요청이 유효한지 확인하고 적절한 데이터를 반환합니다.

## 🏗️ 아키텍처 원칙: Hexagonal Architecture (Port/Adapter)
본 모듈은 **Inbound Adapter** 역할을 수행합니다.
- **REST Controller**: HTTP라는 외부 기술을 통해 내부의 데이터 모델에 접근할 수 있게 해주는 어댑터입니다.
- **Port 호출**: 비즈니스 로직(조회 규칙 등)은 `mart-core`의 Port를 호출하여 처리합니다.
- 기술 세부사항(API 프로토콜)과 핵심 데이터 로직이 분리되어 있어 유지보수가 용이합니다.

## 🛠️ 주요 기능
- **통합 포지션 조회**: 리스크 엔진용 CDM 데이터 제공.
- **시장 데이터 조회**: 수익률 곡선(Yield Curve), 환율 정보 제공.
- **마스터 정보 조회**: 고객, 상품 등 기준 정보 제공.
