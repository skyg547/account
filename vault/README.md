# 🔒 HashiCorp Vault (볼트) - "스위스 은행 특수 금고"

## 1. 초보자를 위한 개념 설명
현재 우리 코드나 `application.yml` 안에는 데이터베이스 비밀번호, JWT 암호화 키 등 민감한 문자열이 그대로 텍스트로 노출되어 있습니다. 이게 GitHub에 올라가면 해커들에게 문을 열어주는 꼴이 됩니다.

**Vault**는 오직 이런 비밀번호들만 전문적으로 보관하는 **'초강력 스위스 은행 금고'**입니다. 
스프링 부트(Spring Boot)는 켜질 때, 소스코드에 하드코딩된 비밀번호를 쓰지 않고, 오직 Vault 금고 서버에 접속해서 그날그날 필요한 비밀번호만 안전하게 꺼내와서 사용하게 됩니다.

## 2. 이 폴더의 역할
- `docker-compose.yml`: Vault 금고 서버를 띄우는 스크립트입니다.

## 3. 실행 및 확인 방법
- MSA 철학에 따라, 이 모듈은 **독자적인 `docker-compose.yml`**을 가집니다.

### ⚠️ 필수 선행 작업
이전에 실행했던 프로젝트 최상단의 `setup-network.bat`를 통해 `account-network`가 이미 만들어져 있어야 합니다.

### 🚀 실행 순서
1. 터미널을 열고 **`vault` 폴더 안으로 이동**합니다. (`cd vault`)
2. 아래 명령어를 실행합니다:
   ```bash
   docker-compose up -d
   ```
3. 브라우저에서 [http://localhost:8200](http://localhost:8200) 에 접속합니다! (Vault UI 관리자 화면)
4. 로그인 화면이 나오면 Token 방식(기본)을 선택하고, `my-root-token-123` 이라는 마스터 키를 입력하면 금고 문이 열립니다. 이곳에 비밀번호를 안전하게 보관할 수 있습니다.
