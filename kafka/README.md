# 📻 Kafka (카프카) - "MSA 대형 전광판 (이벤트 스트리밍)"

## 1. 초보자를 위한 개념 설명
서버 2개가 1:1로 직접 통신(API 호출)을 하다 보면, 한 서버가 죽었을 때 다른 서버도 같이 죽는 불상사가 생깁니다. (강한 결합)
**카프카**는 중앙에 세워둔 아주 크고 튼튼한 '대형 전광판'입니다. 
- `master-data` 서버는 `journal-ledger` 서버에게 직접 전화하지 않고, **"신규 거래처 등록됨!"**이라는 뉴스를 이 전광판에 띄우고 퇴근합니다.
- `journal-ledger` 서버는 나중에 자기가 안 바쁠 때 전광판을 보고 뉴스를 읽어갑니다.

가장 중요한 특징은 **이 전광판의 글씨는 누가 읽었다고 지워지지 않고 하드디스크에 영구 보존**된다는 것입니다! (장애가 났을 때 과거의 전광판 기록을 처음부터 다시 틀어서 데이터를 100% 복구할 수 있습니다.)

## 2. 이 폴더의 역할
- `docker-compose.yml`: 전광판(`Kafka`)과 매니저(`Zookeeper`), 그리고 전광판 화면을 예쁘게 보여주는 브라우저 뷰어(`Kafka-UI`)를 띄우는 스크립트입니다.

## 3. 실행 및 확인 방법
- MSA 철학에 따라, 이 모듈은 **독자적인 `docker-compose.yml`**을 가집니다.

### ⚠️ 필수 선행 작업
이전에 실행했던 프로젝트 최상단의 `setup-network.bat`를 통해 `account-network`가 이미 만들어져 있어야 합니다.

### 🚀 실행 순서
1. 터미널을 열고 **`kafka` 폴더 안으로 이동**합니다. (`cd kafka`)
2. 아래 명령어를 실행합니다:
   ```bash
   docker-compose up -d
   ```
3. 브라우저에서 [http://localhost:8090](http://localhost:8090) 에 접속합니다! (Kafka-UI 관리자 화면)
4. `account-cluster` 가 초록색 불(Online)로 들어와 있다면 카프카 전광판이 완벽히 켜진 것입니다. (이 화면에서 'Topics' 메뉴에 들어가면 전광판에 써진 글씨를 실시간으로 볼 수 있습니다.)
