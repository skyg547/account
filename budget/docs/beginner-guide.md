# 초보자 가이드

예산 계획은 “이 부서가 이 달에 이 계정으로 쓸 수 있는 한도”입니다. 초안은 아직 사용할
수 없고 승인된 뒤에만 돈을 다른 계획으로 옮기거나 실제 집행할 수 있습니다.

- **배정액**: 처음 승인받은 금액
- **전입/전출**: 승인된 두 계획 사이에서 옮긴 금액
- **집행액**: 원천 업무가 실제로 사용한 금액
- **가용액**: `배정 + 전입 - 전출 - 집행`

같은 요청이 네트워크 재시도로 두 번 도착해도 전용은 `requestKey`, 집행은
`sourceType + sourceId + sourceLineId`로 기존 결과를 찾습니다. 키가 같지만 내용이
다르면 조용히 덮어쓰지 않고 실패합니다. 결과 행이 생기기 전의 첫 동시 호출도 256개
영구 잠금 shard 중 같은 행을 먼저 잠그므로 한 번만 저장됩니다.

연말마감 Job은 네 자리 `fiscalYear`를 반드시 받습니다. 날짜를 현재 시각에서 추측하지
않고, 해당 연도의 승인된 계획만 core 규칙으로 `CLOSED` 상태로 바꿉니다. 마감은 그
연도의 영구 제어 행도 `CLOSED`로 바꾸므로 나중에 남은 초안을 승인하거나 새 집행을
추가할 수 없습니다.
