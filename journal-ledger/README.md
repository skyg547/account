# 📝 Journal Ledger Service (전표 및 원장 관리)

## 1. 초보자를 위한 개념 설명
회계 시스템의 진정한 '꽃'이자 가장 핵심이 되는 장부 기록 센터입니다.
회사에서 돈이 나가고 들어오는 모든 거래는 반드시 **'차변(왼쪽)과 대변(오른쪽)의 합이 일치하는 복식부기 전표(Journal)'** 형태로 이곳에 기록되어야 합니다.

## 2. 핵심 비즈니스 로직 (구현 중)
- **전표 룰 엔진 (Rule Engine):** 카프카(Kafka)를 통해 외부에서 "택시비 3만원 결제" 이벤트가 날아오면, 시스템이 알아서 룰을 보고 "차변: 여비교통비 3만 / 대변: 미지급금 3만" 전표를 **자동으로 찍어내는 마법의 분개 생성기**입니다.
- **원장(Ledger) 기록:** 승인된 전표들을 모아서, 특정 계정(예: 현금)에 지금 돈이 총 얼마가 남았는지(잔액)를 집계하는 큰 장부(GL)를 만듭니다.

## 3. 실행 방법
```bash
./gradlew :journal-ledger:api:bootRun
```

## 4. Docker 로 실행하기
이 폴더에 있는 `Dockerfile`을 통해 도커 이미지로 구울 수 있습니다.
```bash
docker build -t account/journal-ledger .
docker run -p 8081:8081 account/journal-ledger
```
