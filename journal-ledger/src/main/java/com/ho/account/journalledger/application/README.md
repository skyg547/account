# Application Layer (앱 제어 센터)

## 📌 초보자를 위한 개념 설명
> **Q. `application` 패키지에는 무엇이 들어가나요?**  
> 은행 접수원의 행동 지침서(흐름)가 들어갑니다. "손님이 돈을 이체해 달라고 하면 -> 1. 장부 규칙(`domain`)을 확인하고 -> 2. 결과에 따라 금고에 돈을 저장(`adapter`)해라" 라는 순서를 정해주는 컨트롤 타워입니다.

## 🚀 규약 (Strict Rules)
이 폴더는 크게 두 개의 주요 파트로 나뉩니다:
1. **`port` (인터페이스):** 내가 외부와 통신할 때 쓸 껍데기 약속(Input, Output).
2. **`service` (유즈케이스 흐름):** 트랜잭션을 걸고(`@Transactional`), DB에서 데이터를 퍼온 뒤 `domain` 레벨에 일을 시키고, 다시 저장하는 제재관.

- 비즈니스 로직(금액 계산, 대차 검증 등)을 여기에 직접 구현하지 마세요! 그건 무조건 `domain`으로 토스해야 합니다.
