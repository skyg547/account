# Domain Layer (핵심 비즈니스 구역)

## 📌 초보자를 위한 개념 설명
> **Q. `domain` 패키지에는 무엇이 들어가나요?**  
> 마치 수학 공식이나 은행의 '규정집'만 모아두는 곳입니다. "분개 대차 균형이 맞아야 한다", "대변의 합과 차변의 합은 같아야 한다" 같은 가장 순수하고 변하지 않는 규칙들이 계산되는 곳입니다.

## 🚀 규약 (Strict Rules)
- **외부 프레임워크 금지:** 이 패키지에 있는 자바 클래스 파일 안에는 `import org.springframework...` 가 절대 단 한 줄도 있어서는 안 됩니다. (오직 순수 Java 객체만 사용).
- **기술 금지:** `@Entity` 같은 JPA 어노테이션도 금지입니다. 
- 데이터 상태 변경 및 내부 금액 계산(`BigDecimal`)은 반드시 이 안의 엔티티 메서드에서만 이뤄져야 합니다.
