# Asset-Lease Beginner Guide

## 1. 이 모듈은 무엇을 하나요

이 모듈은 "회사 자산을 사서 쓰고, 시간이 지나며 가치가 줄고, 나중에 처분하는 흐름"과 "리스 계약을 부채와 자산으로 인식하는 흐름"을 같이 관리합니다.

쉽게 말하면:
- 고정자산: 내 소유 자산
- IFRS 16 리스: 남의 자산을 오래 쓰는 계약을 회계상 자산과 부채로 잡는 것

## 2. 초보자가 먼저 알아야 할 용어

- 취득: 자산을 사서 보유하기 시작하는 것
- 감가상각: 자산가치를 기간에 걸쳐 나눠 비용으로 처리하는 것
- 장부가: 현재 회계장부에 남아 있는 자산 금액
- 잔존가치: 끝까지 쓰고도 남겨둘 가치
- 사용권자산(ROU Asset): 리스로 자산을 사용할 권리
- 리스부채: 앞으로 낼 리스료를 현재가치로 본 부채
- 재측정: 계약 조건이 바뀌어서 리스 자산과 부채를 다시 계산하는 것

## 3. 고정자산은 이렇게 이해하면 됩니다

예시:
- 장비를 12,000에 샀음
- 5년 동안 씀
- 잔존가치 0

그러면 이 모듈은:
1. 취득 시 자산 12,000을 잡고 현금을 줄입니다.
2. 매달 감가상각비를 계산합니다.
3. 시간이 지나면 장부가가 줄어듭니다.
4. 나중에 팔면 처분이익 또는 손실을 계산합니다.

## 4. IFRS 16 리스는 이렇게 이해하면 됩니다

예시:
- 사무실을 3년 리스
- 매달 100 지급
- 할인율 5%

그러면 회계상:
1. 앞으로 낼 리스료의 현재가치를 계산합니다.
2. 그 금액만큼 사용권자산과 리스부채를 동시에 잡습니다.
3. 매달 리스료를 낼 때 일부는 이자비용, 일부는 원금상환으로 나눕니다.
4. 사용권자산은 별도로 감가상각합니다.

즉, 월 지급 한 번에 회계가 한 줄로 끝나지 않고:
- 사용권자산 감가상각
- 리스부채 상환
- 이자비용 인식

이 세 흐름이 같이 움직입니다.

## 5. 이 모듈을 처음 볼 때 추천 순서

1. `POST /api/fixed-assets`
2. `POST /api/fixed-assets/depreciate/{processDate}`
3. `POST /api/fixed-assets/dispose`
4. `POST /api/ifrs16/leases`
5. `POST /api/ifrs16/leases/process-monthly/{processDate}`
6. `POST /api/ifrs16/leases/remeasure`

## 6. 현재 코드에서 꼭 알아야 할 점

- 고정자산과 IFRS 16이 같은 모듈 안에 함께 있습니다.
- 리스 계약 등록 시 IFRS 16 대상이면 초기 인식이 자동으로 수행됩니다.
- 단기리스와 소액리스는 자동 초기 인식에서 제외됩니다.
- 일부 분개는 생성 직후 승인까지 진행합니다.
- 계정과목이 코드값으로 박혀 있는 부분이 있어 운영 계정체계와 다를 수 있습니다.

## 7. 실무에서 자주 헷갈리는 부분

### 리스료를 내면 전부 비용인가요?

아닙니다. IFRS 16 대상이면 전부를 그냥 비용 처리하지 않습니다.

- 일부는 이자비용
- 일부는 리스부채 감소
- 별도로 사용권자산 감가상각비

이렇게 나눠 봐야 합니다.

### 감가상각이 끝난 자산은 어떻게 되나요?

장부가가 잔존가치까지 떨어지면 `FULLY_DEPRECIATED` 상태가 될 수 있습니다. 그래도 자산이 남아 있으면 처분 전까지 기록은 유지됩니다.
